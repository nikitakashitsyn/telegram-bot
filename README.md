# 🤖 AI Репетитор по Математике и Программированию

Telegram-бот для обучения математике и программированию с использованием Google Gemini AI.

Бот умеет:

- 📚 Выдавать математические задачи по уровням обучения
- 🎓 Поддерживать школьные и вузовские программы
- 💻 Работать с задачами Project Euler
- 🤖 Давать интеллектуальные подсказки через Gemini AI
- 📝 Генерировать подробные разборы решений
- 🔍 Проверять числовые ответы
- 🚀 Анализировать программный код пользователя
- 📊 Показывать статистику успеваемости

---

## 🚀 Возможности

### 📚 Учебные режимы

#### Школа
- 5–11 класс
- Случайная генерация задач из Excel-базы
- Проверка ответов

#### ВУЗ
- 1–2 курс
- Поддержка собственных наборов задач
- Автоматическая проверка решений

#### Project Euler
- Получение случайных задач с официального сайта
- Автоматический перевод условия на русский язык
- Проверка программных решений через Gemini AI

---

## 🤖 Интеграция Google Gemini

Используется модель:

```python
gemini-2.5-flash
```

ИИ используется для:

- генерации подсказок;
- анализа кода;
- перевода задач Project Euler;
- составления разборов решений;
- менторской обратной связи.

## 📦 Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
```

### 2. Создать виртуальное окружение

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

## 📋 Формат базы задач

Файл `tasks.xlsx` может содержать несколько листов:

```text
school_5
school_6
school_7
school_8
school_9
school_10
school_11

uni_1
uni_2
```

Обязательные поля:

| Поле | Описание |
|--------|--------|
| id | ID задачи |
| task_text | Условие |
| answer | Правильный ответ |

## 🧠 Проверка решений

### Математика

Для числовых ответов используется сравнение через:

```python
Decimal
```

с учетом вычислительной погрешности.

### Программирование

Код анализируется через Gemini AI:

- проверка логики;
- поиск ошибок;
- анализ алгоритма;
- выдача комментариев ментора.

---

## 📊 Статистика

После завершения сессии пользователь получает:

- количество решенных задач;
- количество правильных ответов;
- процент успешности;
- время выполнения.

## 🛡️ Защита и стабильность

Реализованы:

- асинхронная обработка запросов;
- защита от одновременной записи JSON;
- обработка ошибок Gemini API;
- обработка лимитов Google (429);
- обработка перегрузки серверов (503);
- автоматическая очистка служебных сообщений.
